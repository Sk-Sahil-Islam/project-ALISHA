# Project ALISHA 

**Project ALISHA** is a real-time browser dashboard built for long-distance couples. Share your world, sync your hearts, and build memories together—no matter how many miles apart.

---

## ✨ What's Inside

### 🕐 **Time Core**
- Live clock synchronized between you two
- Countdown to your next meeting
- Days since you met & days together
- Next anniversary reminder
- Daily affirmations that change throughout the day

### 💗 **Heart Telemetry**
- Real-time online/offline presence
- Last seen timestamps
- Mood selector (😊😢😡😴😍) with color-changing reactor
- Partner's current mood display

### ⚡ **Signal Reactor**
- Tap to send instant signals to each other
- Heart particles burst across the screen
- Daily tap counter for both partners
- **Synced heartbeat effect** when you tap together within 5 seconds
- **Send Hug** button with massive hug animation

### 📡 **Field Report (Status)**
- Share what you're doing right now
- Auto-saves drafts locally
- Broadcasts to your partner in real-time

### 🎵 **Shared Playlist**
- Add songs with title, artist, and a personal note
- See who added each song
- Beautiful gradient cards with music notes
- Scrollable playlist with your story in songs

### 🎯 **Bucket List**
- Add future missions (movies, trips, recipes, date ideas)
- Check off completed items together
- Delete when done
- Track your shared adventures

### 📸 **Memory Timeline**
- Add special moments with dates
- Chronological timeline view
- Both partners can contribute
- Your digital scrapbook that grows over time

### 🎨 **Visual Magic**
- Cyberpunk neon-glass aesthetic
- Animated gradients & particles
- Custom glowing cursor with sparkle trail
- Signal & hug particle effects
- Smooth animations throughout

---

## 🛠️ Tech Stack

- **React** + **Vite** - Lightning-fast frontend
- **Firebase Realtime Database** - Instant sync between devices
- **Custom CSS** - Hand-crafted neon HUD design
- **No auth required** - Simple couple code system

## 🎨 Features Breakdown

### Real-time Sync
Everything updates instantly:
- Status changes
- Mood updates
- Reactor taps
- Bucket list items
- Playlist additions
- Memory timeline entries

### Presence Detection
- Automatically detects when partner goes online/offline
- Shows "last seen" timestamp
- Updates presence on tab close

### Local Drafts
- Status and log entries save locally as you type
- Never lose what you were writing
- Syncs when you hit broadcast
